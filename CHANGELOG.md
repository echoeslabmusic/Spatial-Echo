# Changelog

## 1.0.0 - 2026-10-29

First public release.

- Three-head tape echo with Tape Flavor, Drive, head divisions, Sync,
  Ping-Pong, DUB and the Auto-Panic feedback watchdog.
- Spring and Cloud reverbs with three delay/reverb routing relationships.
- Binaural spatial rendering of the linked source or each echo head using
  HUTUBS head-related transfer functions, with motion patterns.
- 62 factory presets in a purpose-grouped browser, user presets, Mix Lock for
  send/return use, and an interactive first-run tour.
- macOS universal installer (AU, VST3, Standalone; macOS 11 or later) and
  Windows installer (VST3, Standalone).
