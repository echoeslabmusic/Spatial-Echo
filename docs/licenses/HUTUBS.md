# HUTUBS HRTF Dataset License (pp1_HRIRs_measured.sofa)

This plug-in bundles the HUTUBS measured HRIR set (`pp1_HRIRs_measured.sofa`),
embedded in the plug-in binary. The source file is
`plugin/Source/Resources/HRTF/pp1_HRIRs_measured.sofa`.
