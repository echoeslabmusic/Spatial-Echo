Read this first: unsigned installer

This installer has no Apple Developer ID signature and is not notarized by Apple. Obtain it from Echoes Lab's official download page. Do not disable Gatekeeper globally.

  1. Quit Ableton Live and any other audio applications.
  2. Open the .pkg installer in Finder.
  3. If macOS blocks it, open System Settings → Privacy & Security, scroll to the security message for Spatial Echo, choose Open Anyway, then confirm Open. Authenticate if prompted. Control-click does not bypass this warning on macOS Sequoia or later. On older macOS versions, use System Preferences → Security & Privacy → General → Open Anyway.
  4. Run the installer. It asks for a Mac administrator password because it installs into the shared plug-in and Applications folders.
  5. Restart or rescan your DAW after installation. Open the standalone app at /Applications/Spatial-Echo.app; use the same Privacy & Security Open Anyway path if macOS blocks it.

Before bypassing a warning, you can verify the package against the accompanying .sha256 file in Terminal:

shasum -a 256 Spatial-Echo-*-mac.pkg

The printed hash must match the one in the accompanying .pkg.sha256 file.

Performance

Spatial Echo is CPU-heavy. At 88.2/96 kHz or with many instances, watch your DAW's CPU meter; if audio crackles, raise the buffer size or use fewer instances.

After Installation

Restart your DAW and rescan plug-ins. This package does not remove older copies under your home Library; duplicate user/system copies can affect which version a DAW loads. If the plug-in remains blocked or missing, email hello@echoeslabmusic.com with the exact message, your macOS version and your DAW.

User presets are stored in:
~/Library/Application Support/Spatial Echo/Presets/

The spatial engine is designed for headphone listening.
