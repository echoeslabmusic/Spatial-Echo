Spatial Echo for Windows

Spatial Echo is free to download and use. Donations are optional.

INSTALL
1. Close your DAW.
2. Run the installer (Spatial-Echo-v<version>-windows.exe).
3. If Windows shows "Windows protected your PC", click "More info", then
   "Run anyway". The installer is not code-signed, so Windows does not
   recognize the publisher.
4. Choose the VST3 plug-in, the standalone app, or both, and finish.
5. Open your DAW and rescan plug-ins.

WHERE IT INSTALLS
- VST3: C:\Program Files\Common Files\VST3\Spatial-Echo.vst3
- Standalone app: C:\Program Files\Echoes Lab\Spatial Echo\Spatial-Echo.exe

SYSTEM REQUIREMENTS
- Windows 10 or 11, 64-bit
- A DAW that supports VST3, if using the plug-in

PERFORMANCE
Spatial Echo is CPU-heavy. At 88.2/96 kHz or with many instances, watch your
DAW's CPU meter; if audio crackles, raise the buffer size or use fewer
instances.

UNINSTALL
Settings > Apps > Installed apps > Spatial Echo > Uninstall.

HELP
Email hello@echoeslabmusic.com with your Windows version, DAW and what
happened.
